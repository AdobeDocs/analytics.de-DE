# Dateneinfüge-API

Die [Dateneinfüge-](https://developer.adobe.com/analytics-collection-apis/methods/data-insertion/)) und [Bulk-Dateneinfüge-](https://developer.adobe.com/analytics-collection-apis/methods/bulk-data-insertion/)) sind beides Methoden, um Server-seitige Sammlungsdaten an Adobe Analytics zu senden. Aufrufe der Data Insertion-API erfolgen jeweils für ein Ereignis. Die Bulk Data Insertion-API akzeptiert Dateien mit Ereignisdaten im CSV-Format, wobei ein Ereignis pro Zeile angegeben wird.

Wenn Sie an einer neuen Implementierung der Server-seitigen Erfassung arbeiten, empfiehlt Adobe die Verwendung der Bulk Data Insertion-API.

Endpunkte, Anfrage- und Antwortformate sowie der vollständige Variablenverweis finden Sie in der Dokumentation [Dateneinfüge-API](https://developer.adobe.com/analytics-collection-apis/methods/data-insertion/) und [Bulk-Dateneinfüge-](https://developer.adobe.com/analytics-collection-apis/methods/bulk-data-insertion/) auf Adobe Developer.
